# 日本即時影像地圖 · Japan Live Camera Map

以地圖聚合日本各地**公開的 YouTube 即時影像** —— 觀光景點、車站、港口、河川、道路等，
可依都道府縣與分類搜尋，並標示直播狀態。

**線上瀏覽 → <https://coolred.github.io/Japan-livecamera/>**

---

## 這個 repo 是什麼

**純靜態網站**。沒有任何後端、沒有建置流程、沒有 API 金鑰。

| 檔案 | 用途 |
|---|---|
| `index.html` | 單頁應用：地圖、清單、搜尋、分類篩選。零金鑰（底圖走免金鑰 CDN，有內建退路） |
| `data/cameras.json` | 機位快照：標題、座標、來源網址、直播狀態、分類 |

沒有伺服器也能跑 —— 直接用瀏覽器開 `index.html` 即可。
放到任何靜態空間（GitHub Pages、S3、本機 `python3 -m http.server`）都能運作。

## 功能

- **地圖 + 清單雙欄**：Leaflet + OpenStreetMap 底圖（免金鑰；2026-10-15 已移除 CARTO），機位以顏色區分直播狀態
- **搜尋**：景點名、都道府縣、提供者
- **分類篩選**：觀光優先 / 顯示全部、只看直播中 / 含未播
- **位置精度**：精確地標 / 市町村級 / 區域代表點三級，低精度會在清單標示原因
- **待確認清單**：標題本身沒有地點（聚合頻道、寵物、地震速報等）集中標記，不假裝已定位
- **疑似停播標記**：人工確認長期未開播的機位會標「疑似停播」，保留觀察、不直接刪除
- **直播狀態**：直播中 / 未播 / 未檢測 / 站外觀看
- **嵌入播放**：直接以官方播放器觀看，不經第三方代理
- **資料新鮮度**：左上角顯示「資料更新於 N 小時前」，超過 12 小時變色提醒

## 資料來源與立場

本專案**不重製、不代理、不轉存任何影像**。
只收錄「某頻道在某地有公開直播」這類**事實性資訊**（標題、座標、來源網址）。

影像本身由 **YouTube** 提供；播放時直接嵌入官方播放器，觀看行為完全在 YouTube 上發生。

收錄來源以**公開的政府／觀光單位開放資料**為主：

- YouTube 公開直播搜尋索引
- 日本地方政府的開放資料（河川水位、道路監視攝影機等）
- 公開的觀光即時影像頻道

若你是頻道擁有者而不希望被收錄，開 issue 告知即可移除。

## 更新方式

**人工推送** —— 無 CI、無自動排程（刻意的：避免資料在無人檢視下變動）。

1. 在來源端重新產生資料快照
2. 重新打包（含金鑰掃描守門，確保不會誤推憑證）
3. 推送到本 repo

網站上的時間標示會反映最新一次更新。

## 已知限制

- **直播狀態是「上次檢測時」的結果，不是即時**。標示為「未播」的仍可能隨時開播
- 部分頻道有地區限制，或需前往 YouTube 觀看
- 部分機位只能定位到市町村層級（座標為推估值）
- 標題沒有任何地點線索的機位（聚合頻道、寵物、地震速報等）只放「區域代表點」，不是真實位置
- 海外機位不在本圖收錄範圍（清單保留 `scope: japan`，未來可做其他區域）
- 資料更新頻率取決於人工推送，非連續更新
